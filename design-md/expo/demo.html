Features

Everything you need to ship native apps

From development to submission, Expo provides the complete toolkit for React Native teams.

Expo SDK

Pre-built native modules for camera, maps, notifications, and more. Write once, run everywhere.

Expo Go

Preview your app instantly on a real device. No build required. Just scan a QR code and go.

Expo Router

File-based routing for universal apps. Navigation that just works across iOS, Android, and web.

Cloud Services

Build and deploy with confidence

EAS powers your CI/CD pipeline for React Native. Build, submit, and update your app without touching Xcode or Android Studio.

EAS Build

Cloud-native app builds in minutes. Queue a build from the CLI and get back a binary you can submit to stores.

EAS Update

Ship JavaScript updates instantly. Fix bugs and push features without waiting for app store review.

EAS Submit

One-command submission to App Store and Google Play. No more manual uploads or provisioning headaches.

How it works

From idea to app store in four steps

Expo streamlines the entire React Native development lifecycle.

1

Create a project

Scaffold with npx create-expo-app

2

Develop & preview

Use Expo Go or a dev build to iterate on real devices instantly.

3

Build & test

EAS Build produces release binaries. EAS Update sends OTA updates.

4

Submit & monitor

EAS Submit sends to stores. Monitor crashes and performance from the dashboard.
