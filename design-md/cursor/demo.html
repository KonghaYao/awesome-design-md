Features

Built for developers who ship

Every feature is designed to keep you in flow — from intelligent autocomplete to multi-file agentic edits.

Tab Autocomplete

Next-edit prediction that anticipates your next change — not just the next token. Multi-line edits in a single tab.

Agent Mode

Give Cursor a task and it will read your codebase, plan the change, edit multiple files, and run terminal commands — autonomously.

Codebase Understanding

Indexes your entire project. Mention any file, function, or type in chat — Cursor knows exactly what you're talking about.

Terminal Integration

AI can run commands, read output, and iterate. Debug errors in your terminal without leaving the editor.

Context-Aware Chat

Reference images, docs, web pages, or specific lines of code. Cursor stitches everything together for precise answers.

Any Model, Your Way

Bring your own API keys for GPT-4, Claude, Gemini, or local models. No vendor lock-in.
