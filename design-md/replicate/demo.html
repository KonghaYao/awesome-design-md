How it works

Run models with
a few lines of code

One API. Every model.

Install the Replicate client, pick a model, and start running predictions. We handle GPU provisioning, scaling, and cold starts — you focus on building.

Every model on Replicate exposes the same clean prediction interface. Switch between models without rewriting your integration code.

Read the docs →
import replicate # Run a model and get the output output = replicate.run( "black-forest-labs/flux-schnell", input={ "prompt": "an astronaut riding a rainbow unicorn", "num_outputs": 1, "aspect_ratio": "1:1", } ) # Output is a URL to the generated image print(output)
