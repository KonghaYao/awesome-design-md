Frequently asked questions

Everything you need to know about running models with Ollama.

What hardware do I need to run Ollama?
Ollama runs on macOS, Linux, and Windows. For most models under 7B parameters, a machine with 8GB of RAM will work well. Larger models (13B–70B) benefit from 16GB+ RAM and a discrete GPU. See our hardware guide for detailed recommendations.
Can I use Ollama in production?
Yes. Ollama's REST API is designed for production use. The Free tier is great for local development and personal projects. For production workloads with higher throughput requirements, the Pro and Max tiers provide data-center-grade GPU infrastructure and guaranteed availability.
Which models are supported?
Ollama supports hundreds of open-weight models including Llama 3.2, Mistral, Gemma, Phi, Qwen, DeepSeek, and many more. Browse the full library at ollama.com/library. You can also import custom models in GGUF format.
How does billing work for cloud tiers?
Pro and Max are billed monthly with no long-term commitment. You can upgrade, downgrade, or cancel anytime. Usage is measured in requests per minute — each tier includes a fixed RPM allowance. For custom enterprise plans, contact hello@ollama.com.
