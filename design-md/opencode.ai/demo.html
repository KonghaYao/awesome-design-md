[+] FAQ
+ How is OpenCode different from Copilot or Cursor?
OpenCode is a terminal-native TUI, not an IDE plugin. It works over SSH, inside tmux, and with any editor. It indexes your entire codebase rather than relying on open-tab context. And it's fully open source (MIT) — no vendor lock-in, no subscription fees.
+ Which LLMs does OpenCode support?
Any model with an OpenAI-compatible API. Claude (Anthropic), GPT-4o (OpenAI), Gemini (Google), Llama (Meta via Ollama), Mistral, DeepSeek — you bring your own API keys. OpenCode ships with sensible defaults for each model family.
− Does OpenCode send my code to any server?
No. OpenCode itself never phones home — zero telemetry, zero analytics. Code is sent to your chosen LLM provider through your own API key; you control where inference happens. Run Ollama locally for fully air-gapped coding.
+ What is OpenCode Zen?
Zen is a managed deployment of OpenCode that runs on your infrastructure with SSO, audit logging, and centralized model routing. It ships the same TUI interface with enterprise controls — RBAC, usage quotas, and SOC 2 compliance.
+ Can I use OpenCode without an internet connection?
Yes. Point OpenCode at a local Ollama instance running Llama, Mistral, or any GGUF model. The TUI, codebase indexer, and terminal runner all work entirely offline. Only model inference needs network — and even that can stay local.
